Who uses it

Fresh category managers at 05:30, before orders close at 12:00, and the store managers who act on transfers and markdowns.

The problem today

Sales sit in Postgres, stock in MySQL, supplier confirmations in a portal and grower news in email. Nobody joins them in time, so the same week one store runs empty and another throws product away.

What it solves

One ranked list of the store-products that will run out or go to waste this week, why, and the action to take, with the source behind every line. The planner approves; nothing is sent automatically.

How the AI gets better after the pilot starts

Better documents

Grower emails and supplier portal notices land in a Volume and are chunked automatically, so this week's news is searchable by 06:00. Vector Search embeddings replace keyword search, so "another supplier" finds "approved alternative" without a synonym list.

Measured, not hoped

Category managers write 50 real questions with the right answer and source. MLflow evaluation scores every prompt, model or retrieval change against that set before it ships, and LLM judges check groundedness and relevance.

Feedback from use

Every answer has 👍 / 👎. Votes are logged with the question, the sources and the model version (to a Delta table in the pilot), and the bad answers become new test questions.

Guardrails stay on

An answer that cites a missing source or a number not in its inputs is never shown. Unity Catalog decides which stores and costs each user can see, for the AI as for the dashboards.
